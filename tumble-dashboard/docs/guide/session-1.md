# Session 1: 화면 틀 만들기

## 프로젝트 파일

- Build the initial Tumble Factory operations dashboard in this app folder.
- Keep the first session limited to creating the app shell; dashboard cards and visual decoration belong in later sessions.

## 화면 서버

- Provide a local development screen server on port `4173`.
- The server must serve the app files from this project and be startable using the project's npm scripts.

## 화면 뼈대

- Create a responsive Korean-language operations dashboard shell for a tumble factory.
- Include a clear page title and a small number of structural sections that establish the screen layout.
- Keep the structure simple and semantic; do not add detailed cards, metrics, or decorative styling in this session.
